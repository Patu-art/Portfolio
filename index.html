HOW I BUILD / CURRENT PROCESS

From public context to a working browser.

The process is still evolving. Keeping it visible forces me to judge the work by decisions and browser behavior, not only screenshots.

01 / FIND

Choose a real context.

Start with an actual business and a reason the digital experience could be clearer or more useful.

02 / RESEARCH

Understand before styling.

Review the business, public feedback, audience, region, competitors, content and practical customer paths.

03 / DIRECTION

Make the visual call.

Choose typography, layout, media behavior and motion because they fit the brief—not because they are fashionable.

04 / BUILD

Make it real.

Implement semantic HTML, responsive CSS and browser interactions instead of stopping at a mockup.

05 / QA

Break the assumptions.

Check small screens, navigation, overflow, readability, keyboard use, reduced motion and missing assets.

06 / SHIP + REVIEW

Publish. Inspect. Improve.

Deploy to GitHub Pages, compare the result with the brief, record what went wrong and take that lesson forward.
